RTDP POC – Implementation Progress Report

Project Overview

The Resource Training & Development Platform (RTDP) is designed to convert bench time into a structured and measurable development process. The platform tracks a resource from bench entry through skill assessment, training, development activities, assessments, and finally deployment readiness.

Completed Modules

1. Authentication & Role-Based Access Control

Implemented secure login and role-based access according to the defined user roles. Access to modules and APIs is controlled based on user permissions.

2. User Management

Implemented user creation, updating, role assignment, status management, and user profile handling.

3. Regions & Practices

Implemented region and practice management with appropriate relationships between resources, practices, and regions.

4. Resource Management

Implemented resource profiles and management of resource-related information, including their practice, region, skills, and current status.

5. Bench Management

Implemented bench tracking with bench start/end dates, bench duration calculation, status/threshold handling, and open bench record management.

6. Skills Matrix

Implemented skill management and resource skill mapping. Resources can have skill levels recorded along with their source, while verified/system-generated skill information is protected from direct modification.

7. Role Profiles

Implemented target role profiles with required skills and proficiency levels. This provides the baseline for identifying skill gaps.

8. Training Catalog

Implemented training tracks, programs, and modules to organize available learning content.

9. Training Assignment & Daily Activities

Implemented training assignment to resources and daily activity tracking to monitor progress against assigned development activities.

10. Assessment Module

Implemented assessment creation, questions, attempts, scoring, and result tracking for evaluating resource knowledge and progress.

Overall System Flow

User Creation → Resource Profile → Bench Tracking → Skill Baseline → Target Role Selection → Skill Gap Identification → Training Track → Training Assignment → Daily Activities → Assessments

This flow establishes the core development pipeline from resource onboarding and bench management to measurable skill development.
